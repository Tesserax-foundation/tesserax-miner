# Security

Report vulnerabilities of the `rx/tess` miner privately: **Security → Report a vulnerability** on
this repository. Do not open a public issue.

Issues that affect the Tesserax chain, such as a hash the network accepts but should not, are
rewarded by the bug bounty of Tesserax:
[docs/bug-bounty.md](https://github.com/Tesserax-foundation/tesserax/blob/main/docs/bug-bounty.md).
